A kingfisher committed to its hunt: the beak has just pierced the surface, the wings are
swept back hard against the dive, and a crown of droplets hangs in the amber light of a low
sun. Every pixel in the frame is generated by code at run time — no photographs, no sprite
sheets, no bundled image data of any kind.

## What this is

`main.ts` is a single-file Node program that draws the whole scene itself. It carries its own
tiny software rasterizer (filled polygons, circles, rotated ellipses, tapered antialiased
lines, alpha blending) and its own PNG encoder (raw scanline assembly, `deflateSync`, CRC32,
chunk framing). Nothing outside the Node standard library is imported, and there are no
dependencies to install.

The drawing happens in one fixed, hand-authored pass: an atmospheric gradient sky and a warm
glow behind the subject, framing reeds and water glints, a low water band with a bright
surface edge, speed streaks trailing the bird's shoulder, then the kingfisher built up as
layered shapes — tail and body facets, far wing, near wing with an inset highlight, the orange
breast and white throat, the rounded teal head with its eye, and the dark beak driving down
into the impact point. Splash ripples, a jagged crown, and scattered droplets finish it.

All geometry is written as literal coordinates and every operation is order-dependent but
free of randomness, timestamps, or iteration over nondeterministic collections. The same
input therefore always produces the same bytes.

Two details worth knowing:

- The scene is rendered at 2x supersampling (`S = 2`) into an offscreen buffer and then box
  filtered down to 1024x1024, which is what keeps the shape edges soft instead of stair-stepped.
- Colors are kept in floating point inside the buffer and only rounded once, during the
  downsample, so accumulation through many blended layers stays stable.

## Running it

```bash
MAKEFUN_OUTPUT_DIR=out node main.ts
```

`MAKEFUN_OUTPUT_DIR` defaults to `/output`; point it anywhere writable. The program creates the
directory if needed and prints the path and byte size it wrote.

## Output contract

- File: `entry.png` inside `MAKEFUN_OUTPUT_DIR`.
- Size: exactly 1024x1024, 8-bit RGB, non-interlaced.
- Budget: comfortably under the 1 MiB cap (roughly 60 KiB).
- Deterministic: repeated runs are byte-for-byte identical.
